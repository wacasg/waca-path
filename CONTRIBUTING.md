# Contributing to WACA path

Thank you for considering a contribution. This repository is prepared for public
open-source release, but the project name and trademark status are still pending
WACA review.

## Basic Rules

- Do not commit secrets, credentials, customer logs, or real user identifiers.
- Use anonymous or synthetic sample data only.
- Keep installation steps reproducible in a user's own Google Cloud project.
- Do not submit code, data, documentation, or prompts that you do not have the
  right to contribute under Apache License 2.0.
- Do not submit patent-encumbered material unless you have the right to grant the
  patent license required by Apache License 2.0.

## Contribution License

Unless a separate written agreement says otherwise, contributions intentionally
submitted to this repository are submitted under Apache License 2.0.

WACA does not require a separate Contributor License Agreement (CLA) at this time.
WACA may introduce a CLA process later if project governance, commercial support,
or legal review requires it.

## Developer Certificate of Origin

Every commit in a pull request must include a Developer Certificate of Origin
sign-off:

```text
Signed-off-by: Your Name <your.email@example.com>
```

You can add this automatically with:

```bash
git commit -s
```

By signing off, you certify that you wrote the contribution or otherwise have the
right to submit it under Apache License 2.0. Use the DCO text at
<https://developercertificate.org/> as the reference.

## Pull Request Policy

- Use focused pull requests.
- Include tests or verification steps when behavior changes.
- Keep public-facing names as `WACA core` and `WACA path`.
- Do not claim trademark clearance, patent clearance, certification, or WACA
  endorsement unless WACA has published that status.
